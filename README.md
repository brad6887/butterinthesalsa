# Butter in the Salsa

A website for friends who put butter in the salsa.

This independent Abbey project owns its Astro site and GitHub Pages workflow. Abbey Root supplies shared tooling. `edge01` is the intended build and publication workstation; GitHub Pages serves the site, and Hostinger manages the domain.

Start with `abbey session`. Operating instructions and release boundaries are in [the site runbook](docs/runbooks/SITE.md).

Repository: https://github.com/brad6887/butterinthesalsa

Initial Pages URL: https://brad6887.github.io/butterinthesalsa/
