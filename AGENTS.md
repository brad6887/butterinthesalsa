# Butter in the Salsa

Follow the Abbey Session Workflow. Site source, content, domain, and Pages workflow belong here; shared tooling belongs in Abbey Root.

Start with `abbey session`. Use `abbey site build`, `abbey site validate`, and `abbey site publish --dry-run` before publication. Capture work with `abbey session capture`.

Do not commit, push, deploy, or change DNS without explicit authorization. A push to main starts the Pages workflow. Preserve unrelated work and inspect final status and diff.
